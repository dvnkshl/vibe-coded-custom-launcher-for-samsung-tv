## What is supported by the documentation

The [TV model-group table](https://developer.samsung.com/smarttv/develop/specifications/tv-model-groups.html) lists the 2023 QCQ60 lineup in 23TV_STANDARD1 under Tizen 7.0. Samsung's [platform information guide](https://developer.samsung.com/smarttv/develop/guides/fundamentals/retrieving-platform-information.html) associates Tizen 7.0 with Chromium 94, newer than the Chromium 85 used to verify this design on the original Q80B. That makes the unchanged web design a plausible candidate for this model; it does not establish native-control compatibility.

The [exact-model support page](https://www.samsung.com/latin_en/support/model.QN75Q60CAFXZA/) lists OS-upgrade downloads. Therefore the generation's original Tizen version is only a starting point. Read the actual installed firmware, Tizen version and web user agent before choosing native APIs or SDK targets. Do not update or downgrade firmware merely to match this kit.
