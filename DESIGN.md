# Scenic Home design

Photography anchors the approved screen. Use a quiet header with weather left, a flat year-progress bar centred and time right, all vertically centred. Year and exact days left sit above the track; calendar-accurate Q1–Q4 labels sit below. Quarter separators are 2px at reference scale (3px at 1080p) in rgba(91,113,126,.78), giving a visible muted slate-grey break without black. No percentages or clickable weather.

Use pearl #f4f6f6, quiet white #d6dedf, glass tint #203034 and scrim #071018. On the Mac use installed SF Pro faces; on Tizen use Samsung/system fallbacks. No bundled Apple fonts. Reference dimensions remain 1280×720, but every CSS length is calculated at the actual viewport size using --ui-scale. The TV application target is 1920×1080, with no whole-canvas scaling transform. At this size the 20px reference header type is 30px. The Mac frame previews the production source at that size.

Keep the modest official device marks, device names only, 26px dock radius and 18px tile radius at reference scale. Selection has 10px background blur, a translucent edge and soft shadow; the dock has 14px background blur. On Chromium 85, use the rounded selection shadow rather than CSS outline, which renders square. Use explicit top/right/bottom/left positioning instead of inset shorthand.

The external Settings SVG has an intrinsic pearl-white stroke; do not depend on a CSS inversion filter for its colour on this TV. Keep Preferences, native Settings, Samsung Home and Edit layout in the bottom row. Their focus state is a thick underline beneath the text, with no outline or filled focus box and no change in label width. All four are plain by default. Only the focused link has an underline, which clears when focus leaves it. Returning Home restores the last input card; closing an in-page panel restores its opener. Preserve the complete input editor and saved mappings. No photo captions, Backgrounds control, rotation controls, Art mode, media shelves, ads or connected-light scenes.

Eleven approved photos rotate every five minutes. Originals and source credits remain in the Mac study; the 0.6.2 TV copy uses exact 3840×2160 JPEGs at quality 90 with preserved focal positions and no source upscaling. Release the outgoing photo after each crossfade. The owner confirmed photos and rounded focus on 0.5.2 and approved the later 0.6.4 composition, dividers and footer focus. 0.7.2 retains those proportions. Physical wake/Home tests remain separate from visual approval.

The optional 30-minute idle shutoff lives in Home preferences, enabled by default. A small warning appears above the dock for the final 30 seconds. It must pause on native/HDMI handoff and reset with trusted remote or pointer activity; photo, weather and clock updates do not reset it. Keep idle permission and errors inside Preferences without adding permanent Home clutter. See `IDLE_POWER.md`.
